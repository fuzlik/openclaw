# AGENTS.md — инструкция для нейросети на домашнем ноуте

Ты устанавливаешь и настраиваешь **OpenClaw** для владельца этого репо.  
Читай файлы в порядке ниже и **действуй сам**, без меню вариантов, пока не упрёшься в секрет или необратимое.

## Порядок чтения (обязательно)

1. `docs/decisions.md` — зафиксированные решения (не пересматривай без просьбы)
2. `docs/owner.md` — кто владелец, контекст
3. `docs/security.md` — границы и запреты
4. `docs/runbook-home.md` — пошаговая установка (исполняй)
5. `docs/telegram.md` — канал Telegram
6. `docs/verify.md` — критерии готовности
7. `config/openclaw.desired.json5` — целевая форма конфига (без секретов)

## Цель

На **домашнем** Windows-ноуте:

- установлен OpenClaw CLI (актуальный stable)
- локальный Gateway на `127.0.0.1:18789`, автозапуск после логина
- workspace = `<этот-репо>/workspace`
- модель через **OpenRouter** (`OPENROUTER_API_KEY`, primary `openrouter/auto`)
- Telegram: бот + pairing только для владельца
- Control UI открывается локально
- секреты **не** в git

## Не делать

- Не ставить / не чинить OpenClaw на рабочем ноуте Alabuga
- Не коммитить `.env`, токены, `~/.openclaw/openclaw.json` с секретами
- Не открывать Gateway в LAN / Funnel / публичный интернет без явной просьбы
- Не подключать Alabuga (storm, gitlab corp, Happ, `_контекст/.env`)
- Не спрашивать «какой вариант?» — решения уже в `docs/decisions.md`

## Когда остановиться и спросить владельца (один короткий вопрос)

- Нет `OPENROUTER_API_KEY` (владелец создаёт на https://openrouter.ai/keys)
- Нет Telegram bot token (@BotFather) — нужен интерактив владельца
- Нужны права администратора Windows / reboot / WSL install, если native path окончательно сломан

## Успех

Все пункты `docs/verify.md` зелёные. Краткий отчёт владельцу: версии, URL UI, статус Telegram, что осталось сделать вручную (если что-то).
